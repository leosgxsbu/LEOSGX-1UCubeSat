# IARU Amateur Satellite Frequency Coordination Request

This repository contains the **IARU (International Amateur Radio Union) Amateur Satellite Frequency Coordination Request** for the **LEO-Gamma Ray Mapping** CubeSat mission.

## What This Document Is

The IARU is responsible for coordinating radio frequencies used by amateur radio satellites worldwide. Because satellites have global reach, uncoordinated frequency use can cause harmful interference to other missions and ground stations. This document is the standardized **application form (v40)** that satellite operators must submit to the IARU Satellite Advisor to request frequency coordination before launch.

The form serves to:
- Certify that the mission meets the ITU Radio Regulations' definition of the amateur and amateur-satellite services (RR 1.56 / 1.57), including operating **without pecuniary interest**.
- Provide the IARU Satellite Advisor and Advisory Panel with the technical and administrative details needed to check the proposed frequencies against other coordinated and planned satellites.
- Document licensee, organizational, and regulatory (ITU API/A filing) information tied to the request.

## Mission Summary

| Field | Detail |
|---|---|
| **Satellite name** | LEO-Gamma Ray Mapping |
| **Type** | Educational 1U CubeSat, Stony Brook University |
| **Notifying administration** | FCC (USA) |
| **Licensee** | Will Farr |
| **Payload** | CsI(Tl) scintillator + SiPM array for mapping short Gamma-Ray Burst (GRB) fluence/duration profiles |
| **Requested band** | 435–438 MHz (UHF amateur satellite allocation) |
| **Modulation** | 9600 baud GFSK, AX.25 packet framing |
| **EIRP** | +20 dBm (100 mW) |
| **Data access** | Fully open-source telemetry, decodable via the global SatNOGS ground station network |
| **Commercial interest** | None declared |

## Purpose of Submission

This completed form is intended to be sent to the IARU Satellite Advisor (`satcoord@iaru.org`) to obtain frequency coordination prior to launch, ensuring the mission's UHF downlink/uplink does not conflict with other amateur satellite operations. Coordination is a prerequisite step alongside filing Advance Publication Information (API) with the ITU through the national administration (FCC).
