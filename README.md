# SYSTEM-3 / LEO-GRM

Open-source 1U Gamma-Ray Spectrometer CubeSat by the Stony Brook University Nanosatellite Division.

**Website:** https://leosgxsbu.github.io/LEOSGX-1UCubeSat/

## Repository layout

```
LEOSGX-1UCubeSat/
├── CAD/                 # STEP / STL models
├── EasyEDA Pro/         # PCB source
├── Gerber Files/        # Manufacturing files
├── Proposal/            # IARU / FCC / proposals
├── Research/            # Literature & datasheets
├── Physics/             # Link budgets & models
├── Code/                # Flight firmware
├── Materials/           # BOM / procurement
├── docs/                # Next.js project website
├── .github/workflows/   # GitHub Pages deploy
└── README.md
```

## Website (local)

```bash
cd docs
npm install
npm run dev
```
